# Política de segurança

## Reportar uma vulnerabilidade

Não abra uma issue pública para vulnerabilidades. Reporte de forma privada pela aba
**Security** do repositório no GitHub, em **"Report a vulnerability"**
(GitHub Security Advisories):

https://github.com/ivobraatz/pitwall/security/advisories/new

Inclua, se possível, a versão afetada, os passos para reproduzir e o impacto que você
imagina. Vamos responder, confirmar o problema e combinar a correção e a divulgação com você.

## Versões suportadas

Suportamos apenas a última versão `0.x` publicada (pacotes `pitwall-sdk` no npm e
`Pitwall.AspNetCore` no NuGet). Correções são lançadas na última versão.
